CodeGrid / Workspace / Explorer

Explorer & Editor

The Explorer maps the workspace filesystem into a recursive browser tree and opens selected files in the editor.

Browse

Load and navigate the workspace tree.

Open

Select a file and load its content into the editor.

Edit

Edit plain-text source files directly in the browser.

Save

Persist UTF-8 file content back to the workspace.

Create

Create new workspace files from the IDE.

Refresh

Reload the current workspace tree.
