Getting Started

Run CodeGrid locally, open the browser workspace, and start working inside the project workspace.

Prerequisites

Node.js 18+

Required runtime for the current project.

npm

Used to install and manage project dependencies.

Git

Required for source-control workflows.

Bash + script

Required by the live terminal session.

Install

Terminal 
git clone <your-codegrid-repository-url>
cd CodeGrid
npm install

Start

Terminal 
npm start

Open http://127.0.0.1:8899 in your browser.

Termux

Termux 
chmod +x run-codegrid.sh
./run-codegrid.sh
