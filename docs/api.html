API Reference

The local CodeGrid server exposes JSON endpoints for workspace, Git and GitHub operations.

Method Endpoint Purpose
GET/api/healthServer and runtime status.
GET/api/workspaceWorkspace metadata.
GET/api/filesRecursive file tree.
GET/api/file?path=…Read a file.
PUT/api/fileSave a file.
DELETE/api/fileDelete a file or directory.
GET/api/github/statusGitHub connection status.
GET/api/github/reposRepository list.
POST/api/github/deviceStart device authorization.
POST/api/github/device/pollPoll authorization.
POST/api/github/linkLink workspace remote.
POST/api/git/cloneClone repository.
POST/api/git/pullPull changes.
POST/api/git/commitCommit changes.
POST/api/git/pushPush changes.
