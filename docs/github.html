CodeGrid / Source Control / GitHub

GitHub

CodeGrid uses GitHub device authorization to connect a workspace with a GitHub account.

Client configuration

.codegrid/github.env 
GITHUB_CLIENT_ID=your_github_oauth_client_id

Repository connection

Authorize

Start the GitHub device authorization flow.

Browse repositories

Load repositories belonging to the connected account.

Link workspace

Associate the current workspace with a GitHub repository.

Disconnect

Remove the current GitHub connection from CodeGrid.

Security

Never commit GitHub credentials or expose the .codegrid/ directory.
