Safety

CodeGrid provides direct access to local files, processes and Git operations. Run it only in environments where you trust the users and code being executed.

Security model

Process permissions

The Web Shell runs with the permissions of the process that started CodeGrid.

Workspace access

File operations are intended to remain inside the configured workspace.

Git operations

Clone, pull, commit and push operations modify real repositories.

Preview

Preview serves workspace content through the local CodeGrid server.

Recommended deployment

Trusted local or private-network use

Do not expose an unauthenticated CodeGrid instance directly to the public internet.

Authentication

Add authentication before exposing the service to other users.

TLS

Use HTTPS/TLS when CodeGrid is accessed over an untrusted network.

Credentials

Never commit GitHub tokens or private configuration.

Repositories

Review repositories before cloning or executing their scripts.

Protected files

Local credentials 
.codegrid/github.env
