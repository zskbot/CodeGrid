Architecture

CodeGrid keeps the browser UI thin while the local Node.js server manages workspace files, Git, GitHub and the shell. 

Browser UI
    │
    ├── HTTP ───────► Express APIs ─────► Workspace / Git / GitHub
    │
    └── WebSocket ──► Bash shell ───────► ~/CodeGrid/workspace

Browser preview ────► /preview/ ────────► Workspace files

Runtime model

Browser

Provides Explorer, Editor, Shell and Preview interfaces.

Express server

Provides HTTP APIs and static file serving.

Workspace

Stores editable project files and preview content.

WebSocket shell

Connects the browser to a persistent Bash process.
