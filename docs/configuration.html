Configuration

Configure the CodeGrid server through environment variables and local GitHub authentication settings.

Environment variables

Variable Example Purpose
PORT 3000 Changes the HTTP server port.
GITHUB_CLIENT_ID your_client_id GitHub device authorization client identifier.

Change the port

Terminal 
PORT=3000 npm start

GitHub configuration

.codegrid/github.env 
GITHUB_CLIENT_ID=your_github_oauth_client_id
Keep credentials private.

Do not commit GitHub credentials or authentication tokens to the repository.
